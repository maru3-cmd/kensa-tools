使い方

  1. サンプル（何個で何g）と、必要なら風袋を入れて単重を決めます。
  2. 小分けの表示値（総重量）を入れて「追加」を押すと、個数と累計が出ます。
  3. 小分けごとに追加でき、合計個数・合計重量が記録されます（この端末内に保存）。
計算のしかた
はかりの重さから個数を割り出す単重換算です。
・正味重量 … 正味 = 総重量 − 風袋（容器）
・個数（生の値）… 個数 = 正味 / 単重
・表示する個数 … 上の値を四捨五入した整数
・ずれ … 生の値 − 整数。これが 0 から離れているほど、単重が実物と合っていない／欠品や異物が混ざっている疑いになります
・単重を実測から出すとき … 単重 = サンプルの正味 / サンプル個数（個数を多くとるほど精度が上がります）
・のせられる上限の目安 … (はかりの秤量×0.9 − 風袋) / 単重（秤量いっぱいは使わない前提で0.9掛け）
単重のばらつきがそのまま個数の誤差になります。ずれが大きいときは、個数を疑う前に単重を測り直すのが早いです。

例 ── 10個=25g、250g を計量

10個で25g のサンプル。250g 計量したら何個？

サンプル 10個=25g ／ 風袋0 ／ 表示値 250 →「追加」

読み方：単重 2.5g/個、250g ÷ 2.5 = 100個。
