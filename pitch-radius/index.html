角度から穴ピッチ中心からの半径と角度 → 2穴の距離

使い方と例を見る

使い方

  1. 2穴が同じ半径なら「同半径(角度)」を選び、半径 r と 2半径線の間の角度 θを入れます（弦の公式 L=2·r·sin(θ/2)）。
  2. 半径が違うときは「異半径」に切り替え、r₁・r₂・θを入れます（余弦定理）。
  3. 図面が直径（φ・PCD）で書かれているときは、上の「直径で入れる」を押してからその数字をそのまま入れてください。半分にする計算は要りません。
  4. 角度は 60 でも 60 30（度 分）でも入れられます（入力欄の下のボタンで10進／度分秒を切替）。下に穴間ピッチ L が出ます。
  5. 穴径（キリ径）を入れると、下にノギスを当てたときの読み（外−外・内−内）が中心間と並んで出ます。電卓で足し引きする必要はありません。穴の大きさが違うときは「穴ごとに指定」へ（片方だけ入れたときは、もう片方も同じ径として計算し、その旨を表示します）。
  6. 穴径は「キリ（バカ穴）」「M（ねじ下穴）」のボタンからも選べます。キリはボルトを通す穴（M8なら9キリ）、Mはめねじの下穴（M8なら6.8）です。押したときだけ一覧が開くので画面は伸びません。
  7. 角度に ±公差（例 ±0.2°）が付いているときは、いちばん下の「角度公差 → ピッチの許容範囲」へ。実測ピッチを入れると合否も出ます。
計算のしかた
中心から2つの穴までの距離と、その間の角度から、穴間の直線距離を出しています。
・半径が同じとき … L = 2R × sin(θ/2)（二等辺三角形の底辺）
・半径が違うとき … L = √( r₁² + r₂² − 2·r₁·r₂·cos θ )（余弦定理）
・直径で入れたときは R = φ/2 に直してから同じ式を使っています（内部は常に半径）。
・PCD 表示 … 2R　　・弧長 … R × θ[rad]
・角度公差 ±Δ からピッチの許容範囲 … θ を ±Δ 振って上の式に入れ直しています。
同半径の式は余弦定理の特別な場合（r₁=r₂）で、√(2R²−2R²cos θ) = 2R·sin(θ/2) と同じものです。ピッチは弦であって弧ではありません。
・「キリ（バカ穴）」の出典 … JIS B 1001:1985 付表「ボルト穴径 dh」。1級(密)・2級(中)・3級(粗)を選べます（既定は2級）。 M12・M14・M16 は旧JIS(1968)では 14・16・18 で、1985年版で 13.5・15.5・17.5 に変わりました。旧い値の図面もあるので確かめてください。
・「M（ねじ下穴）」の出し方 … 並目と細目を切り替えられます。いずれも D − P を 市販のドリル径（0.1刻み）に丸めた、一般的な下穴表の値です。ボタンの ×○ が計算に使ったピッチです。 細目は呼び径8mm以上でピッチの組合せが数種類あるため（JIS B 0205「小ねじ類、ボルト及びナット用の細目ねじの選択基準」）、 ふつうに使われる組合せを採っています。 下穴は材質やひっかかり率で変わります。実際に開いている穴を測って入れるのが確実です。
・ノギスの読み … 外−外 = 中心間 + (d₁+d₂)/2、内−内 = 中心間 − (d₁+d₂)/2。 穴径が同じなら、その径をそのまま足し引きすることになります。
・実測の欄は、穴径を入れてあれば外−外・内−内・中心間のどれで測ったかを自動で見分けます。 読みの差は穴径ぶん（φ9なら9mm）あるのに公差は0.1mm台なので、取り違えようがありません。

例 ── 半径50・角度60°

中心Oから半径50の2穴が、角度60°離れているときのピッチは？

同半径(角度) ／ 半径 r 50 ／ 角度 θ 60

読み方：L = 2×50×sin(60°÷2) = 50.000mm。
