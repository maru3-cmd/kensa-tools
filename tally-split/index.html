荷札（確定個数と、数え方）

使い方

やること

  1. 各荷札の確定個数（荷札に書かれた数）を入れます。空にすれば、ただ数えるだけにも使えます。
  2. 数え方を選びます。物に合わせて荷札ごとに変えられます。
  3. かんたん＝数えた分を次々足す（5・14・8…）。仕切り＝行×列×満載段＋端数段。組＝1組の数×組数＋端数。
  4. 数えた計と残りが自動で出ます。合致で緑✓、入れすぎは赤。全荷札が合致すると上が「全て合致 ✓」。
数え方
3つの数え方を用意していて、それぞれ足し算だけです。
・かんたん … 数えた分を次々足す … 合計 = Σ(入れた数)
・仕切り … 箱の仕切りで数える … 合計 = 行 × 列 × 満載の段数 + 端数の段の数
・組 … まとまりで数える … 合計 = 1組の数 × 組数 + 端数
・確定個数との差 … 差 = 合計 − 確定個数（＋なら数え過ぎ、−なら足りない）
端数の段・端数の組はそのまま足すだけで、掛けません。仕切りで「3段満載＋4段目に12個」なら 6×5×3 + 12 = 102 です。
計算そのものは単純なので、合わないときは数え方の取り違え（満載段数に端数の段を含めてしまった等）を先に確かめてください。

例

仕切り：6×5の仕切り、3段満載＋4段目12 → 102個。

組：2個1組が22組＋端数12 → 56個。

かんたん：5・14・8 → 27個。

データは端末内にのみ保存され、どこにも送信されません。
数えた計が確定個数に合うかを、荷札ごとに確認できます。
