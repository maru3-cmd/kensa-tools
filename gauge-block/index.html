使い方

  1. 入れ方を上で選びます。寸法で… 作りたい寸法をそのまま入れます。公差で… 図面のまま基準寸法と上下の許容差を入れます（例 50 に −0.09 / −0.06）。
  2. 下に組み合わせが枚数の少ない順に出ます。行を押すと、その組の積み重ねが図に出ます。
  3. 枚数は少ないほど確かです。密着させる面が増えるほど、すき間と誤差が積み上がります。4枚以内で探しています。
  4. ぴったり作れない寸法もあります（このセットの最小刻みは 0.001mm、小数第4位は 5 だけ）。そのときはいちばん近い組み合わせを差つきで出します。
112個組の内訳（JIS B 7506 / ミツトヨ BM1-112 相当）
　1.0005 … 1個
　1.001・1.002 … 1.009（0.001とび）… 9個
　1.01・1.02 … 1.49（0.01とび）… 49個
　0.5・1.0 … 24.5（0.5とび）… 49個
　25・50・75・100 … 4個
計算のしかた
　寸法は 0.0001mm 単位の整数に直して足し合わせています。 小数のまま足すと 1.0005 のような値で誤差が出て、ぴったりかどうかの判定が狂うためです。
　同じ寸法のゲージは1枚しか使えません（セットに1個ずつのため）。
　※ここで出るのは呼び寸法での組み合わせです。実際の寸法は検査成績書の値で確かめてください。
