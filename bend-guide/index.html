使い方と例を見る

使い方

  1. まず直線の入れ方を選びます。実長＝真っすぐな部分だけの長さ、交点寸法＝曲げの延長線が交わる点までの長さ。図面がどちらで入っているかで選んでください。
  2. 「直線 → 曲げ → 直線 …」の順に入れます。曲げはθ（＋左/−右）とR。
  3. 「＋ 曲げ+直線を追加」で杖型・S字・多段曲げも表現できます。最初から弧で始まる形は直線1を0に。
  4. 入力すると形状が描かれ、展開長（切断長）・端点間距離・外形が出ます。
  5. 手元の図面と向きが違うときは、図の上の「図の向き」で左右反転と90°回転を組み合わせて合わせられます（8通りすべて出せます）。向きを変えても、入力した寸法・角度・展開長は変わりません。図・座標・外形が同じ向きになるだけです。
  6. 実物大で写すときは「段ボールに写す座標」を開き、原点を「左下」にします。段ボールの左下の角を(0,0)にして、表の X を横・Y を縦に測れば点が打てます（数字は全部プラスなので、図が段ボールからはみ出しません）。左の辺に始点・下の辺に終点を乗せたいときは、その向きになっているかを画面が教えます。なっていなければ「その向きにする」を押すと一発で合います。打つ点（接点）とコンパスの中心が出ます。中心が図の外に出る曲げには、弦・矢高と中間点が出るのでコンパス無しで描けます。
計算のしかた
パイプ・チューブを中心線（管の軸）の「直線＋円弧」として扱い、頂点をつないで座標を出しています。
・進む向き … 曲げ角を順に足していく … φᵏ = φᵏ₋₁ + 曲げ角ᵏ（真っすぐの向きが0°、＋が左曲げ）
・次の頂点 … (x, y) = 前の頂点 + L × (cos φ, sin φ)（Lは交点寸法から円弧の食い込み分を引いた実効長）
・曲げ部の円弧 … 中心線の曲げ半径 R と曲げ角から各頂点に当てはめます。弧の長さは R × 角度[rad]
・実長で入れたとき … タンジェント長を足し戻して交点寸法にしてから組み立てます … 交点寸法 = 実長 + T(前の曲げ) + T(次の曲げ)、T = R × tan(θ/2)
　Rが大きいほど T は伸びます（R200・45°で T=82.843mm）。同じ形でも実長と交点寸法では数字が大きく違います。
・弦と矢高（中心が遠いとき） … 弦 = 2R·sin(θ/2)、矢高 = R(1−cos(θ/2))
・図の向き … 見せ方だけを変えます。左右反転は x → −x、回転は画面上で時計回りに (x, y) → (y, −x) を回数ぶん。反転→回転の順に当てるので、この2つで8通りすべてになります（上下反転＝左右反転＋180°）。回転は始端を中心にするので、始端はどの向きでも動きません。展開長・端点間距離・弧長・弦は向きで変わりません。
・端が「0」のとき … 弧から始まる／弧で終わる形として扱います
・展開長 = 直線部の合計 + 円弧部の合計（中心線の長さ）
・角度は度・分・秒でも入れられます（1°47′24″ の形式）
管の曲げでは中心線の長さが切断長のよい目安になりますが、実際は材料の伸びや曲げ方（マンドレルの有無など）で少し変わります。量産の切断長は試し曲げの実績で補正してください。

例 ── L字（直線50・90°R10・直線50）

真っすぐな部分が50 → 90°曲げ(R10) → 真っすぐな部分が50 のL字パイプの切断長は？

入れ方=実長 ／ 直線1 50 ／ 曲げ θ90 R10 ／ 直線2 50

読み方：展開長（切断長）≈ 115.708mm、外形 60×60。
同じ「50 / 50」でも交点寸法で入れると 95.708mm（外形 50×50）になります。入れ方でこれだけ変わるので、図面がどちらか確かめてください。

図の向き 図面の向きに合わせられます。寸法・角度・展開長は変わりません。
