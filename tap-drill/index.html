使い方

  1. ねじサイズ（M8 など）と、切削タップ／転造を選びます。並目/細目のピッチは自動です。
  2. 慣用の下穴 D−P（呼び径−ピッチ）と、基準めねじ内径が出ます。
  3. 下の「実測の判定」に、タップ後のめねじ内径やボルトのおねじ外径の実測を入れると、2級相当(6H/6g)の許容限界(JIS B 0209-2)で合否が出ます。並目・細目どちらも対応。
  4. ひっかかり率の目標％や材質別の限度帯から、より詳しい推奨下穴も出せます。
出典と計算のしかた
ねじの基準寸法は JIS B 0205（一般用メートルねじ・並目／細目）、公差は JIS B 0209-1（許容限界寸法の算式）と JIS B 0209-2（許容限界寸法の表）から出しています。
・下穴径 … 下穴 = D − P（ひっかかり率100%の理論値。D=呼び径、P=ピッチ）
・ひっかかり率 H% を指定したとき … 下穴 = D − 1.0825 × P × H/100
・めねじ内径の許容限界 … D1min = D − 1.0825P に 6H の公差 TD1 を足した範囲
・おねじ外径の許容限界 … 基準の外径に 6g の基礎となる許容差 es と公差 Td を当てた範囲
・等級指定のないメートルねじは 6H（めねじ）／6g（おねじ）＝旧2級相当・はめあい区分「中」が適用されます（JIS B 0209-1）。
・めっき指定のねじの公差はめっき前の寸法に適用します（JIS B 0209-2）。
許容限界は JIS B 0209-2 の表（並目15行・細目13行）と全行一致することを確認済みです。
