使い方

やること

  1. 各プーリーの位置（X・Y）と直径を、図面の寸法どおり入れます。プーリー1を X0・Y0 の基準にすると楽です。
  2. 通常のプーリーは外掛け、内側から押すテンションプーリーは内掛けを選びます。
  3. ベルトが接する順に並べます（上から順に 1→2→3→…→1 でひと回り）。
  4. 上に図面上の周長が出ます。接線と巻き付き弧を厳密に合算した値です。図でベルト経路も確認できます。
  5. 歯付きなら歯ピッチを選ぶと歯数の目安、仕様書の全長を入れると差（参考）が出ます。
計算のしかた
ベルトを「プーリーに巻き付いた弧」と「プーリー間をまっすぐ渡る接線」に分けて、厳密に合算しています。近似式は使っていません。
・接線の長さ … √( D² − (Rj − Ri)² )　（D=中心間距離、Ri・Rj=両プーリーの半径。同じ側に巻くときは差、逆向きなら和になるよう符号を持たせています）
・接線の向き … φ = atan2(Δy, Δx) + acos( (Rj − Ri) / D )　これで共通接線の角度が決まります
・巻き付き弧 … r × ω　（ω=巻き付き角[rad]。出ていく接線と入ってくる接線の角度差から求め、内掛け／外掛けで回る向きを分けています）
・周長 … Σ(接線) + Σ(巻き付き弧)
「プーリーが近すぎて経路が作れません」と出るのは |(Rj − Ri) / D| > 1 のとき、つまり一方が他方を内側に飲み込んでいて共通接線が引けない配置です。
出るのは図面の配置どおりの理論周長です。実際に使うベルトは規格の呼び長さから選び、テンションで調整するので、正解は図面と部品表です。

例 ── 2プーリー＋内掛けテンション

P1（X0・Y0・φ100・外）、P2（X300・Y0・φ100・外）、テンション（X150・Y80・φ40・内）。ベルトが下側テンションで押し下げられた経路の周長が出ます。
