使い方

  1. 図面の指示に PCD・穴数・ボルト（相手）の径を入れます。等配でないときは「不等配」にして各穴の角度を入れます。
  2. キー溝や位置決めピンがあって部品を回せないときは「回転できない」を選びます。回せるかどうかで結論が変わることがあります。
  3. 測る前の準備を開くと、ノギスが届くかどうかが分かります。測っている最中は閉じてください（答えを見ながら読むと、人によって値が変わってしまいます）。
  4. 穴径を入れます。ばらつきが小さければ「共通」だけで構いません。ボール盤で径がばらつくときは穴ごとに入れてください。
  5. 実測した距離を入れます。外−外／内−内／中心間のどれで測っても構いません。入れた数字から候補を選んで表示します（ちがっていれば札を押して直してください）。
  6. 下に実効PCDが出ます。しっかりと座標では、各穴のずれとボルトが通るかも出ます。

3つの入れ方

  1. かんたん… 隣どうしのピッチを一周ぶん。速いですが、出せるのは等価PCDと隣り合う間隔までです。 穴ひとつずつのずれ・位置度・組付きは出せません（穴N個の位置を決めるには 2N−3 組の測定が要るのに、隣接ピッチはN組しかないためです。3穴だけは例外で確定します）。
  2. しっかり… 2つ跨ぎ・対辺も測って位置を確定させます。こちらが本来の使い方です。
  3. 座標… 三次元測定機や「図面まるごと穴ピッチ(30)」の X・Y をそのまま。
計算のしかた
・読みを中心間に直す … 外−外 C = L −(dᵢ+dⱼ)/2、内−内 C = L +(dᵢ+dⱼ)/2。 同じ組を外−外と内−内の両方で測ったときは C =(L外+L内)/2 となり、穴径が式から消えます。
・かんたん（隣接ピッチのみ） … 全穴が同じ円上にあるとみなし、 Σ 2·asin(pᵢ ÷ 2R) = 360° を満たす R を二分法で求めます。R は一つに決まります。
・しっかり（総当たり） … 図面の穴位置を出発点に、 各測定について |Pᵢ−Pⱼ| − C が最も小さくなる座標をレーベンバーグ・マルカート法で求めます。
・実効PCD … 求めた穴位置に図面の穴配置を倍率つきで重ね、その倍率 s から 実効PCD = s × 図面PCD。
・重ね方 … ふつうの最小二乗だと、大きく外れた穴に基準が引っ張られてずれが全穴に薄く散り、 どの穴が原因か分からなくなります。そこで外れている穴の重みを下げながら重ね直しています （重み (1−(e/3M)²)²、M は各穴のずれの中央値）。外した穴は表に ＊ を付けています。
・各穴のずれ … 重ねた残りを、円の中心から見て径方向（内外。外向きが＋）と 周方向（回り方向。真上0°・時計回りが＋）に分けたものです。
・組付き判定 … 部品はのび縮みしないので倍率なしで、ずらし・回しだけを動かします。 穴ごとのすきま半径 cᵢ =(穴径ᵢ − ボルト径)÷2 に対し max( ずれᵢ − cᵢ ) を最小にする位置を探し、0以下なら通ります。
穴が大きく開いていれば、その穴の逃げは増えます。考え方は最大実体（Ⓜ）に似ていますが、 ここでやっているのは理想の剛体・真円・この姿勢での幾何的な組付きチェックであって、 規格の最大実体公差方式（MMR）の評価そのものではありません。図面にⓂの指示があるときは、その規格に従ってください。
出典：円に内接する多角形の辺長から外接円半径が一つに決まることは初等幾何の性質によります。

例 ── PCD100 に 6穴、隣が 0.8mm ずれている

一周のピッチが 50 / 50.8 / 49.2 / 50 / 50 / 50。φ9キリ、M8ボルト。

PCD 100 ／ 6穴 ／ ボルト 8 ／ 穴径 9 ／ かんたん

読み方：実効PCD は 100.00（＝PCD自体は正常）。穴3 が回り方向へ +0.77mm。 図面判定は規格外ですが、組付きは回せるなら通ります。

例 ── PCD が 99 になっている

一周のピッチが全部 49.5。割り出しは完璧なのに、ピッチが図面（50.0）より小さい。

読み方：実効PCD は 99.00、各穴の回り方向のずれは ゼロ。 つまりPCDそのものが1mm小さい。この場合はずらしても回しても直らず、φ9穴・M8では通りません。
