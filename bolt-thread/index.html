ボルトのねじ部長さ全ねじ／半ねじの判定・円筒部の寸法

← ポータル
使い方と計算のしかた

使い方

  1. 上で六角穴付きボルトか六角ボルトを選びます。ねじ部長さ b の決まり方が2つの規格でまったく違うので、必ず現物に合わせて選んでください。
  2. ねじの呼びを押して、呼び長さを入れます。
  3. その長さに半ねじ（首下に円筒部のあるもの）の規格品があるかを判定します。図面が半ねじを指示しているのに規格には無い、という食い違いをその場で押さえるためのツールです。
  4. 半ねじがある場合は円筒部の長さ ℓs・ℓg も出ます。現物をノギスで測って突き合わせられます。
  5. 半ねじが無い場合は代わりに指示できる最短の呼び長さも出します。差し戻すときに「では何にすればよいか」まで書けます。

計算のしかた

・ねじ部長さ b … 規格で呼び径ごとに決まっている値です。
　六角穴付きボルト（JIS B 1176）は呼び径ごとに1つだけ。b ＝ 2d + 12（M1.6 のみ 15）。
　六角ボルト（JIS B 1180）は呼び長さで3段階に変わります。
　　ℓ ≦ 125 → b = 2d + 6　125 < ℓ ≦ 200 → b = 2d + 12　200 < ℓ → b = 2d + 25
　★この違いを取り違えると、長いボルトで必ず外します。
・円筒部 … 規格の式そのままです。ℓg,max ＝ ℓ − b　ℓs,min ＝ ℓg,max − 5P（P はピッチ）。
　ℓg は首下の丸みや不完全ねじ部を含んだ長さ、ℓs は完全な円筒部だけの長さです。
・全ねじの判定 … 規格の呼び長さ表で、その呼び径に半ねじの数値が載っている最小の呼び長さを境にしています。 それより短いものは規格の表では全ねじの範囲です。
・不完全ねじ部 … 全ねじ品の首下は 3P 以内、ねじ先は 2P 以内と規格で決まっています。

言い切れること・言い切れないこと

・「規格品は全ねじだけ」とは言えます。ただし「市場に無い」とは書いていません。 規格の全ねじ範囲でもメーカーによっては半ねじを作っていることがあるためです。 差し戻すときは「規格品は全ねじ。半ねじが要るなら特注」と伝えるほうが、後から覆りません。
・表の範囲を超えた呼び長さは「無い」ではなく「この表の範囲外」と出します。 入っているのは六角穴付きが一般に流通する範囲、六角ボルトが部品等級A・第1選択の抜粋です。 等級Bや第2選択、さらに長いものは別の表になります。
・いちばん短い側は判定していません。短すぎて流通範囲に入らない呼び長さがありますが、 その境目は手元の資料で確認できていないので、全ねじ範囲としか出しません。
・六角ボルトの 125〜130 と 200〜220 は判定を止めます。 六角ボルトには本体規格（ISO準拠）と附属書（旧JIS）の2系統があり、 b の切り替わりが 125／200 と 130／220 で違います。この帯だけ b が食い違うので、現物確認をお願いする作りにしてあります。
出典：JIS B 1176:2014（六角穴付きボルト）表3および ℓ・ℓs・ℓg の表／JIS B 1180:2014（六角ボルト）呼び径六角ボルト 並目ねじ 部品等級A 第1選択の表。 b の値・半ねじが載る最小の呼び長さ・表の上限は、いずれも規格の抜粋表から拾って手計算（ℓ − b）と突き合わせてあります。

例 ── 図面に「M6×25 半ねじ」と書かれていた

取引先から返ってきた品物が全ねじだった。図面は半ねじ指示。どちらが正しいか。

六角穴付きボルト ／ M6 ／ 呼び長さ 25

読み方：全ねじだけ。ねじ部長さ b は 24 で、呼び長さ 25 との差が 1 しかなく、円筒部が取れません。M6 で半ねじが要るなら呼び長さ 35 から。25 のままなら特注になります。

例 ── 半ねじの現物が来たので円筒部を測る

M10×60 の六角ボルト（半ねじ）。首下の円筒部は何mmあるはずか。

六角ボルト ／ M10 ／ 呼び長さ 60

読み方：半ねじあり。ねじ部長さ b は 26、円筒部は ℓs 26.5 以上・ℓg 34 以下。ノギスで首下の丸みまで含めて測ると 34 以下、ねじ山の始まりまでなら 26.5 以上に入っていれば規格どおりです。
