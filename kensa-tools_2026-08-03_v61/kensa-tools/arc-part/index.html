使い方

  1. 板の幅と高さを入れます。
  2. 図面で中心からの寸法が入っている角を選び、その角から見た中心の位置を入れます。右が＋X、上が＋Y です。下の図で位置が合っているか確かめてください。
  3. 円弧の R を入れます。スペース区切りで何本でも入れられます（溝の両側や、同心の溝が何本もあるとき）。
  4. どの端面から測るかを選び、測る間隔を決めます。
  5. 端面に沿った位置ごとの端面から円弧までの距離が表に出ます。ノギスやハイトゲージをその位置に当てて読み合わせます。
計算のしかた
・板の左下の角を原点、右を＋x、上を＋y とした部材の座標で考えます。選んだ角と入れた X・Y から、 円弧の中心 (cx, cy) を部材の座標に直します。
・測る端面を u 軸（端面に沿った位置）、そこから板の内側へ向かう向きを d 軸（端面からの距離）とすると、 中心は (cu, cd) に移ります。円の式は (u − cu)² + (d − cd)² = R² なので
　d = cd ± √( R² − (u − cu)² )
位置 u ごとにこれを解き、板の中に入っている解（0 ≦ d ≦ 板の奥行き）だけを出しています。 解が2つとも板の中に入るときは、手前と奥の両方を出します。
・端面との交点 … d = 0 とおいて u = cu ± √(R² − cd²)。
・いちばん近づくところ … u = cu のとき d = cd − R。この u が端面の長さの中にあるときだけ表示します。
・円弧が板を通らないときは、その旨を出します（R が小さすぎる／大きすぎる、中心の位置が違う、など）。
規格ではなく純粋な幾何計算です。中心が板の外にあっても、出る数字は端面が基準のままになります。

例 ── 400×150 の板を横切る溝（R650 と R662）

右上の角から中心が X+300・Y−75（つまり板の右のほう、少し下がった位置の先）。溝の両側が R650 と R662。

幅 400 ／ 高さ 150 ／ 右上の角 ／ X 300 ／ Y −75 ／ R「650 662」／ 左の端面 ／ 25mmごと

読み方：左の端面から R650 までは、高さ0で 54.34、高さ75で 50.00、高さ150で 54.34。 まん中がいちばん近いことが表と「いちばん近づくのは位置 75.00 で 50.00」の行から読めます。 同じ行の R662 は 42.26 / 38.00 / 42.26 で、差の 12 が溝の幅です。
