このツールが直すこと

  1. 図面が部材から遠く離れた中心を基準に円弧を描いていて、「どこから伸ばしているの？」となる場面のためのツールです。設計は組立の中心や回転軸から寸法を出しますが、検査は部材を手に持って端から測るので基準が噛み合いません。ここを翻訳します。
  2. 原点 (0,0) ＝ 円弧の中心です。そこから部材を 距離・角度（または X・Y）と回転角で置きます。円弧は原点中心なので R と 開始角・終了角を入れるだけです。
  3. 答えはすべて部材の角と端面からの寸法で出ます。部材が傾いていても、出てくる数字は「この角から何mm・この端から何mm」です。
  4. 角度は真上0°・時計回り＋。回転角は部材の高さ方向（Hの向き）が真上から時計回りに何度傾いているかです。
計算のしかた（「どうやって出しているの？」と聞かれたとき用）
図面座標（原点＝円弧の中心）で交点を求め、部材座標（角と端面が基準）に直して表示しています。角度は真上0°・時計回りが＋。
・部材の置き方 … 幅方向 ex = (cos φ, −sin φ)、高さ方向 ey = (sin φ, cos φ)（φ=回転角）。選んだ基準点を原点から L × (sin θ, cos θ) の位置に置き、そこから左下の角を逆算します
・円と端面の交点 … 端面上の点を B + t·e と置き、|B + t·e|² = R² を t の2次方程式として解きます（B=端面の始点、e=端面の方向、|…|は原点＝円弧中心からの距離）。解が端面の長さの中に入っていて、かつ角度が開始角〜終了角の範囲にあるものだけを採用
・端からの深さ … 端面上の点 Q から内向き法線 n の方向に |Q + d·n|² = R² を解き、正の最小解を深さとします
・いちばん深いところ … 原点から端面への垂線の足 F を求めて 深さ = R − |F|。位置は F の端面上パラメータ
・円弧上の穴 … 配置半径 × (sin θk, cos θk) を部材座標に直し、0 ≤ x ≤ W かつ 0 ≤ y ≤ H で部材内かを判定
・部材座標への変換 … x = (P − 左下の角)·ex、y = (P − 左下の角)·ey（内積）
規格ではなく純粋な幾何計算です。部材が傾いていても、出る数字は部材の角と端面が基準のままになります。

例 ── 端から150mm外側の中心に R180（ご相談の部品）

幅400×高さ120 の部材の下端面の中点が、中心から真上150mm。その中心から R180 の円弧（−40°〜40°）が描かれ、部材に触れた部分だけざぐられている部品です。

部材 400 × 120／基準点＝下辺の中点／距離150・角度0／回転角0
円弧 外R180／開始−40・終了40
穴 配置半径170／3個／起点−20／ピッチ20

読み方：円弧が下端面を横切るのは左下から 100.501 と 299.499。一番深いのは左下から200.000で深さ30.000。穴3つは下端面から 9.748・20.000・9.748 に出ます。

端末内計算
① 部材（長方形）
回転角 0 なら W は右向き・H は上向き。傾いて付く部材でも、出る寸法は部材の角と端面が基準のままです。
② 円弧（中心は原点）
開始角から時計回りに終了角までが円弧の範囲です。内側の R を入れると、ざぐりの帯として内外の両方を計算します。
③ 円弧上の穴（丸穴のときだけ）
穴径を入れると、部材の端にかかる穴に印が付きます（接触している部分だけざぐる部品で、どこまでが実物にあるかの目安）。
④ 端からの寸法
任意の位置での 端からの深さ
⑤ 穴の位置
穴数を入れると一覧が出ます。
