使い方

  1. 端面からの並び寸法（各穴の位置）を、1行ずつ、または一括貼り付けで入れます。
  2. 隣接ピッチ・最小/最大・平均が出ます。基準穴を切り替えると「穴3から穴7まで」も読めます。
  3. 等間隔のはずの穴なら「等ピッチ判定」で、各穴のズレ（累積）と合否が出ます。
計算のしかた
一列に並んだ穴の位置（累積）と隣どうしのピッチを行き来させ、等ピッチからのずれを出しています。
・位置 → ピッチ … pᵏ = 位置ᵏ₊₁ − 位置ᵏ
・ピッチ → 位置 … 位置ᵏ = 位置₁ + Σ p（累積和）
・等ピッチの理想値 … 理想ᵏ = 位置₁ + (k−1) × p₀
　p₀ は図面ピッチを入れればその値、空欄なら実測から p₀ = (最終位置 − 最初の位置) / (穴数 − 1) を自動で使います
・位置のずれ … ずれᵏ = 実測位置ᵏ − 理想ᵏ　最大値を ± で表示
・ピッチのばらつき … |pᵏ − p₀| の最大値
・合否 … ずれが ±公差 に入っているか
逆パターン（図面がピッチで書かれているとき）は「穴間ピッチを入れる」に切り替え、ピッチを順に入れると端（または穴1）からの累積位置が出ます。その数字をコンベックスで追えます。「端から1穴目まで」を入れれば端面基準、空欄なら穴1が0になります。
「ピッチは全部合っているのに位置がずれる」ことがあります。ピッチの誤差が同じ向きに積み上がると累積するためで、この表はその積み上がりを見るためのものです。図面がピッチ指示か累積寸法指示かで、どちらを見るべきかが変わります。

測定時の留意点
  • コンベックスは引っかけと突き当てで爪のガタ分だけ動きます。全ての穴を同じ端面・同じ測り方で測ると、ガタが共通誤差になり、隣接ピッチ（引き算）では相殺されます。
  • 穴の中心はコンベックスでは狙えません。縁で読む場合は「両縁の中央」を位置としてください。全穴で同じ縁（例：手前縁）を読めば、これもピッチでは相殺されます。
  • ↴（行の右）… その欄を確定して次へ進みます。末尾で押すと新しい行が増えます（キーボードの「次へ／Enter」と同じ）。
  • ↰（行の左端）… 途中の穴を入れ忘れたときに。押すとその行の位置に空欄が入り、そこから下が1つずつ下がります。
  • 等ピッチ判定は先頭穴を基準に合わせています。先頭穴自体が端面からずれている場合、その分は全体の平行移動になり、位置ズレには出ません（隣接ピッチ誤差には出ます）。
  • この画面は1列（1方向）の並びを見るものです。縦横2方向に広がる穴群は、基準点・基準線から見る TOOL-27 を使ってください。
検査ミニポータル｜計算はすべてこの端末の中で行われます。入力値は端末のブラウザ内にのみ保存され、消去ボタンで完全に削除できます。
