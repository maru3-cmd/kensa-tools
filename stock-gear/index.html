使い方と計算のしかた

使い方

  1. 型番をそのまま入れます（例 SUS1-48J16・KHG2-20R・SRF2-1000）。種類・モジュール・歯数（ラックは長さ）・穴径（J の後ろ）を読み取って下の欄に入れ、材質・焼入れ・研削・精度も出します。
  2. いちばん上に出る歯先円直径（外径）が、ノギスで実際に測る値です（内歯車は内側の歯先円、ラックはピッチ）。ピッチ円直径は測れません。
  3. 実測の外径を入れると、歯数・モジュールの取り違えがないかを見ます（歯が1枚違えば外径は m だけ違います）。
  4. 「型式の一覧と違い」に、KHK の記号の読み方と、型式ごとの材質・焼入れ・研削・精度をまとめてあります（記号で探せます）。
  5. 下の「軸穴とキー溝」に、キー溝の大きさ（幅 × 深さ）と、穴・キー溝の合格範囲が出ます。J の付いた型番なら穴径も自動で入ります。
  6. 全長はカタログの値を入れると、KHK の資料の許容差で合格範囲が出ます。

型番の読み方（KHK 小原歯車工業）

SUS1-48J16 ＝ SUS（ステンレス平歯車 SUS303）＋ 1（モジュール）－ 48（歯数）＋ J16（追加工品・穴径16）
・J ＝ KHK の追加工品（J シリーズ）。標準の歯車に穴径（H7）・キー溝（JIS B 1301 普通形 Js9）・止めねじのねじ穴を加工したもの。 　J の後ろの数字が穴径（mm）です。φ50 を超える穴は H8。キー溝と歯の位置は合わせていません。
・KHK のカタログはキー溝を「5×2.3」＝ 幅 b₂ × 深さ t₂ と書きます（穴径16 なら 5×2.3）。
・シリーズの記号：S…平歯車／材質 S＝S45C・M＝SCM415・K＝SCM440・SU＝SUS303・P＝MC901・N＝MC602ST・D＝ジュラコン・BS＝黄銅・L＝焼結。 　後ろに A＝ボスなし、G＝歯研削、Y＝薄歯幅 などが付きます（例 SSA＝S45C のボスなし、SSG＝S45C の研削）。

計算のしかた

・歯先円直径 ＝ m ×（z ＋ 2）　ピッチ円直径 ＝ m × z　歯底円直径 ＝ m ×（z − 2.5）
　圧力角20°・転位なしの標準歯車として出します（KHK の平歯車の外径はこの式どおり。例 SUS1-48 は外径50、SS3-19 は63）。 　SSGS の10歯だけは転位（x＝＋0.5）なので外径が合いません。
・またぎ歯厚 W は m・cos20°・{π(k − 0.5) ＋ z・inv20°}、またぎ歯数 k ＝ z÷9 ＋ 0.5 を丸める。 　バックラッシの無い理論値で、既製品は歯厚を薄く作るので実測は少し小さく出ます。
・外径の許容差はカタログに載っていません。なので外径では合否を出さず、取り違え（歯数・モジュール違い）を見ます。
・全長の許容差（KHK の平歯車・はすば歯車）：30 以下 0 ／ −0.10、30 を超え 100 以下 0 ／ −0.15、100 を超える 0 ／ −0.20。上は 0 です。

軸穴とキー溝（JIS B 1301）

・穴径からキー（b×h）・キー溝の幅 b₂・深さ t₂を JIS B 1301 の表で引きます。区分は「〜を超え〜以下」（例 φ17 は「12 を超え 17 以下」なので 5×5）。
・受入れで測るのは穴側：穴径、キー溝の幅 b₂、穴の反対側から溝の底まで（d＋t₂）。軸側の t₁ は参考に出します。
・幅の公差は決まりで変わります：普通形 Js9（いちばん多い・KHK の J もこれ）／締込み形 P9／滑動形 D10。 　旧JIS（1959）は寸法そのものが違います（φ25 で 新 8×3.3、旧 7×3.0）。図面に「旧JIS」とあるときだけ使ってください。
・★「適用する軸径」は JIS でも参考です。キーは伝わるトルクで選ぶので、図面に b×t₂ があれば図面が正です。

入っていないもの

・計算するのは、式をカタログの値で確かめた種類だけ：平歯車・CP 平歯車、はすば歯車の KHG（軸直角、ねじれ角 21°30′）と SH（歯直角、15°）、内歯車 SI・SIR、ラック（ピッチ）。 　マイタ・かさ歯車・ねじ歯車・ウォーム・はすばラックは角度・進み角で径が変わるので、型式の説明だけ出します。
・ボス径・歯幅・ボスの長さは型番からは決まらないので、カタログの値で見てください。
・精度等級（N8 など）の許容値は歯車試験機で測るものなので出していません。
・型番を読めるのはKHK だけです。ほかのメーカーは、種類・モジュール・歯数を手で入れれば同じ計算ができます。

記号の読み方と、違いの意味

記号のならび：材料 ＋ 種類 ＋ その他の英字、モジュール、「−」、歯数（ラックは長さ）、後ろに付く記号。 例 SSG2-20 ＝ S（S45C）＋ S（平歯車）＋ G（研削）、m2、20歯。KRGF2-500H ＝ K（SCM440）＋ R（ラック）＋ G（研削）＋ F（両端加工）、m2、長さ500、H（焼入れ）。

  • 材料：S＝S45C、M＝SCM415、K＝SCM440、SU＝ステンレス（SUS303、ラックは SUS304）、P＝MC901（ナイロン）、N＝MC602ST、D＝ジュラコン（ポリアセタール）、BS＝快削黄銅、L＝焼結、A＝アルミ青銅（AG・AN）、B＝りん青銅（BG）、C＝鋳鉄（CG）
  • 種類：S＝平歯車、H＝はすば歯車、I＝内歯車、R＝ラック、M＝マイタ、B＝かさ歯車、N＝ねじ歯車、W＝ウォーム、ホイールは末尾が G（AG・BG・CG・PG）
  • その他：G＝研削、A＝ボスなし（平歯車。マイタの SMA・SUMA などは「穴仕上げ済みの形」）、Y＝薄歯幅、S＝ピニオンシャフト（SSS・SSGS）やスパイラル（SMS・SBS）、F＝両端加工（ラック）・フェアロックハブ（SUSF）、D＝取付穴（ラック）、O＝丸ラック、U＝鉄心入り（樹脂）、R＝リング（SSR・SIR）、CP＝円ピッチ（歯の間隔を mm で決めた系列）
  • 後ろの記号：H＝焼入れ品（焼入れプラス）、HL＝レーザー焼入れ、R・L＝ねじれの向き（右・左）、J＋数字＝穴・キー溝の追加工（数字は穴径）

違いの意味（同じモジュール・歯数でも、ここで強さ・寿命・精度・値段が変わります）

  • 焼入れなし（S45C の SS・SR など）…いちばん標準。削ったまま。軽い・中くらいの力に。
  • 調質（K○○ の KS・KRF など）…焼入れ焼戻しで全体を粘り強くする。歯面は特に硬くない。
  • 歯面高周波焼入れ（SSG・-H など）…歯の表面だけ硬く（50〜60HRC）して摩耗に強く。中は粘る。
  • 浸炭焼入れ（M○○ の MSGA・MRGF など、SCM415）…表面に炭素を入れて硬く、芯は粘る。いちばん強い。
  • レーザー焼入れ（-HL）…歯面をレーザーで焼入れ。ひずみが少ない。
  • 研削（G）…焼入れのあとに歯を研いで仕上げる。精度が上がり（N5〜N7、ラック 等級1〜3）、静かでなめらか。切削は削ったまま（N8 など）。
  • 精度等級…平歯車などは JIS B 1702-1 の N5〜N12、ラックは KHK の等級 1〜8（DIN 3962 の Q5〜Q12 にあたる）。数字が小さいほど精密。
  • ステンレス（SU）…錆びにくいが硬くない。樹脂（P・N・D）…軽く静か、油なしでも使えるが、熱と吸水で寸法が変わる。

ボタンの意味（新JIS・旧JIS・普通形・締込み形・滑動形・H7・H8）

新JIS と 旧JIS：キー溝の決まり（JIS B 1301）は途中で作り直されています。新JIS＝今の決まり（ISO に合わせたもの）、旧JIS＝昔の決まり（JIS B 1301-1959）。 同じ穴径でもキーの大きさと溝の深さが違います（φ25：新 8×3.3、旧 7×3.0）。図面・カタログに「旧JIS」と書いていなければ新JISです。

普通形・締込み形・滑動形（新JIS の中の3つ）：キーの留め方の違いで、溝の大きさは同じ、幅の公差だけが違います。

  • 普通形（Js9）…いちばん多い。歯車・プーリ側の溝は 基準の ± に同じだけ。KHK の J・ミスミなど既製品の追加工はたいていこれ。
  • 締込み形（P9）…キーを打ち込んで固く留める。溝は 基準より少し狭い（マイナス側）。
  • 滑動形（D10）…歯車・プーリが軸の上を滑って動く。溝は 基準より広い（プラス側）。

旧JIS（E9）・旧JIS（F7）：昔の決まりの2種と1種。溝の大きさは同じで、幅の公差が E9（広め）か F7（少し広め）。

穴の公差 H7・H8：穴径の許容差の記号。H は「基準より小さくならない（0 〜 ＋）」、数字は等級で小さいほど厳しい。既製品の穴はふつう H7、KHK の J は φ50 を超えると H8。

Js9・P9・D10 などの記号：英字が基準からどちらにずらすか（Js ＝ 上下に同じだけ、P ＝ 狭い側、D・E・F ＝ 広い側、H ＝ 0 から広い側、N ＝ ほぼ 0 から狭い側）、数字が幅の大きさ（等級）です。
