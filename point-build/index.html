使い方と計算のしかた

なにをするツールか

図面に寸法が書かれていない先端の点（斜めに切った円弧ガイドの角、細いタブの先端、端面の中心など）を、 穴・線・円の交わりとして組み立て、穴からその点までの距離と穴から線までの垂直距離を出します。 作った点は次の点の材料に使えるので、角 → 角を通る線 → その先のタブの角、と積み上げられます。

使い方

  1. 「穴を足す」で穴を入れます。XY で直接、または PCD＋角度で。
  2. 「線・円を足す」でガイドの外R・内R（円：中心＋R）や切断線（線：2点、または1点＋角度）を置きます。
  3. 「点を足す」で交点などを作ります。答えが2つある作り方（三角形・線×円）は、図に ①② が出るので押して選びます。
  4. 下の表に、穴から各点までの距離と、穴から各線までの垂直距離が出ます。表のマスを押すと図にその距離が出ます。

点の作り方

・中点 … 2点の真ん中。端面の中心（外側の角と内側の角の間）に。
・三角形の頂点 … 点Aから距離a・点Bから距離bの点。答えは2つ（A→Bの左側①／右側②）。
・角度と距離 … 点Aから角度θ・距離L。
・線上を進んで直角にずれる … A→Bの向きに a 進み、直角に b ずれる（b の＋は A→B の左）。
・線×線 … 2本の線の交点。平行なら出ません。
・線×円 … 線と円の交点。答えは2つ。線の向き（Aから、または角度の向き）に沿って手前が①・奥が②。
・線 … 2点を通る／1点を通って角度θ。円 … 中心の点＋R。

角度の向き

既定は真上0°・時計回り（位置系のツールと同じ）。図面が右0°・反時計回り（数学の向き）で書いてあるときは上の切り替えで。 切り替えは入れてある角度の数字をそのまま読み替えます。

計算のしかた

・線は「通る点 p と向き d」。線×線 は p₁+t·d₁ ＝ p₂+s·d₂ を解きます。
・線×円 は |p+t·d − c| ＝ R を t の二次方程式で解きます。判別式が負なら交わりません。
・三角形 は2つの円（A半径a・B半径b）の交点。|a−b| ≦ AB ≦ a+b でなければ作れません。
・穴から線までの垂直距離 は |d × (P−p)|（d は単位ベクトル）。線の延長上まで含めた距離です。 切断面の実際の範囲の外に足が下りることもあるので、図で足の位置を見てください。

試作の段階で入っていないこと

・図面まるごと穴ピッチ（TOOL-30）の入力の持ち込み。形になってから。
・記録（📒）。
・円と円の交点は「三角形の頂点」と同じものなので、そちらで。
・角度の入力は度の小数だけ（度分秒はまだ）。

例 ── 斜めに切った円弧ガイドと、その先のタブ

中心Oの円弧ガイド（外R320・内R250）にPCD570の穴が3つ。先端を斜めに切り、そこから細いタブが伸びている。穴から「外側の角」「内側の角」「端面の中心」「タブ先端の2つの角」までの距離が欲しい。

穴 H1〜H3 ／ 円 C1=外R・C2=内R ／ 線 L1=切断線 ／ 点 P1〜P6

読み方：P2 が切断線と外Rの角、P3 が内Rの角、P4 がその中点＝端面の中心。P5・P6 がタブ先端の2つの角。表に H1〜H3 からの距離が並びます。
