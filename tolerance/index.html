使い方

  1. 「軸(小文字)」か「穴(大文字)」を選び、下のチップで公差域クラス（h7 など）を選びます。
  2. 呼び寸法（図面の基準寸法φ）を入れると、上下の許容差と最大・最小許容寸法が出ます。
  3. 実測値を入れると、公差域内かどうかを合否判定します（空欄なら許容差だけ表示）。
  4. 実測値を入れると、その寸法が同じ記号の何等級に相当するかも出ます。h8 の図面で「h11相当になります」と出れば、等級を3つ外していることがひと目で分かります（IT16 まで探します）。
  5. めっき品は「めっき厚(片面)」を入れると、めっき前の狙い寸法が出ます（実測がめっき前なら切替で判定。図面公差はめっき後に適用）。
  6. 下の「はめあいのすきま」で、穴×軸の組合せの最大・最小すきま（負ならしめしろ）が出ます。
出典と計算のしかた
数値は JIS B 0401-1／-2（対応国際規格 ISO 286-1／-2）の基本公差 IT と基礎となる許容差の表から引いています。式は次のとおりです。
・軸 h … es = 0／ei = −IT　　穴 H … EI = 0／ES = +IT
・軸 d, e, f, g … es = 表の値（負）／ei = es − IT
・軸 k, m, p, s … ei = 表の値／es = ei + IT
・js／JS … ±IT/2 の対称公差
・穴 K, M, P, S … ES = −(軸の表の値) + Δ／EI = ES − IT、Δ = ITn − IT(n−1)
　Δ を足すのは K・M・N は IT8 以下、P〜ZC は IT7 以下 のときだけです（それより粗い等級と、呼び寸法3mm以下は Δ=0）
・上・下の限界寸法 … 呼び寸法 + es(ES)/1000、呼び寸法 + ei(EI)/1000（µm→mm）
・はめあい … 最大すきま = 穴ES − 軸ei、最小すきま = 穴EI − 軸es（負ならしめしろ）
・めっき … 図面公差はめっき後に適用。片面 t µm なら径は軸 −2t／穴 +2t 動くので、めっき前の狙い＝図面値 − その分。
・相当等級 … 同じ記号で等級を細かい側から順に当て、実測偏差が最初に収まった等級を表示します。
　・IT11〜IT13 … JIS B 0401-1 の表の値をそのまま持っています（h11〜h13 の合否判定に使うため）。
　・IT14〜IT16 … ISO 286 の「IT6以上は5等級ごとに10倍」の関係から出しており、相当等級の目安にだけ使っています。
